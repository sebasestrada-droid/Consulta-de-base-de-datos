# Consulta-de-base-de-datos
ShiverSale – Consultas SQL con Oracle

Descripción



El proyecto consiste en desarrollar consultas SQL para la empresa ficticia ShiverSale, dedicada a la venta de calzado, utilizando Oracle SQL Developer para obtener información relevante mediante funciones SQL y expresiones condicionales.

Objetivos

Desarrollar consultas que permitan analizar y organizar información de la empresa a través de tres casos:

- Análisis de facturas: clasificación de montos, formatos de RUT, formas de pago y filtros por fecha.
- Clasificación de clientes: validación de datos, tratamiento de valores nulos, clasificación de créditos y extracción de dominios de correo.
- Stock de productos: conversión de monedas, alertas de inventario, cálculo de descuentos y clasificación de productos.


Funcionalidades implementadas

- Funciones SQL de caracteres, fechas y conversión.
- Manejo de valores nulos.
- Expresiones condicionales ("CASE").
- Restricciones y filtros de datos ("WHERE").
- Ordenamiento de resultados ("ORDER BY").
- Variables de sustitución.
